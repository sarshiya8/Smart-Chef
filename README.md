# 🍳 Smart Chef

A C-based kitchen assistant application built using the Windows API.

## ✨ Features

- **Recipe Management** — Manage cooking recipes.
- **Fridge Inventory** — Keep track of kitchen ingredients.
- **Cooking Queue** — Organize recipes to prepare.
- **Shopping List** — Keep track of items to buy.

## 🛠️ Tech Stack

- C
- Windows API

## 💻 Platform

Designed for Windows.

## 🚀 Getting Started

1. Clone or download this repository.
2. Open `main.c` in a C development environment that supports the Windows API.
3. Compile the program using a compatible Windows C compiler and the required Windows libraries.
